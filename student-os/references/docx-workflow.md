# DOCX Workflow

Use this reference for Word documents.

## Common goals

- import a document into markdown
- extract paragraphs and tables for note/review use
- prepare a markdown-first draft that can later be exported back to docx

## Output preference

- narrative documents -> `templates/imported-reference.md`
- structured coursework documents -> course `references/` or `notes/`

## Handling rules

- preserve paragraph order
- render simple tables into markdown tables
- keep section titles visible
- do not invent formatting that is not supported by the extracted content
