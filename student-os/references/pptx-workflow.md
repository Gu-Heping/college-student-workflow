# PPTX Workflow

Use this reference for slide decks and lecture materials.

## Common goals

- extract slide titles and readable text
- turn a deck into a markdown slide summary
- feed course or review workflows with lecture structure

## Output preference

- generic deck import -> `references/slides/`
- course-specific lecture material -> `courses/<course>/references/`
- later note/review distillation -> hand off to `course-tutor` or `review-coach`

## Handling rules

- keep slide order
- preserve slide titles whenever available
- summarize unreadable or image-heavy slides conservatively
