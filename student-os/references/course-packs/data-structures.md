# Data Structures Course Pack

Use this pack for `data-structures` homework and review work.

## Directory and naming

- Homework pages: `courses/data-structures/homework/topic-*.md` or week-based files
- Homework solutions: `courses/data-structures/homework/topic-*-solution.md`
- Chapter reviews: `courses/data-structures/reviews/topic-*.md`
- Problem analyses: `courses/data-structures/reviews/problem-*.md`

## Typical artifact patterns

- Homework may mix code, pseudocode, and explanation.
- Review sheets should separate definitions, algorithm ideas, complexity notes, and common traps.
- Problem analysis pages are useful when a single exercise deserves a deeper explanation.

## Quality expectations

- Distinguish between final answer, reasoning, and code sketch.
- Complexity claims should be explicit, not implied.
- If code is illustrative only, label it as pseudocode or sketch.
- When the answer depends on unstated assumptions, state them.

## Tags and links

- Tags: `course/data-structures`, `homework`, `review`, `algorithms`
- Link coding-heavy tasks back to the course dashboard and related task file.
