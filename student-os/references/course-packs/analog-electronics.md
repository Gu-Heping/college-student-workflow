# Analog Electronics Course Pack

Use this pack for `analog-electronics` homework and review work.

## Directory and naming

- Homework pages: `courses/analog-electronics/homework/week-XX.md`
- Homework solutions: `courses/analog-electronics/homework/week-XX-solution.md`
- Chapter reviews: `courses/analog-electronics/reviews/chapter-XX.md`
- Problem analyses: `courses/analog-electronics/reviews/problem-*.md`

## Typical artifact patterns

- Homework usually arrives as weekly problem sets.
- Solutions should favor stepwise reasoning and explicit circuit assumptions.
- Reviews should extract methods, common mistakes, and quick recognition cues.

## Quality expectations

- State circuit context before formulas.
- Do not skip from setup to final answer without intermediate reasoning.
- If an answer is based on reference material, label it as reference-backed.
- If the derivation is uncertain, mark it as `solution_status: needs-review`.

## Tags and links

- Tags: `course/analog-electronics`, `homework`, `review`, `circuits`
- Always link homework and solutions back to `index.md` and `dashboard.md`.
- Link deadline tasks when a due date exists.
