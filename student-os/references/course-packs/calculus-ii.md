# Calculus II Course Pack

Use this pack for `calculus-ii` homework and review work.

## Directory and naming

- Homework pages: `courses/calculus-ii/homework/section-X-Y.md` or dated homework files
- Homework solutions: `courses/calculus-ii/homework/section-X-Y-solution.md`
- Chapter reviews: `courses/calculus-ii/reviews/chapter-XX.md`
- Weekly digests: `courses/calculus-ii/reviews/week-XX-digest.md`

## Typical artifact patterns

- Homework often references sections and problem numbers.
- Solutions should preserve problem-number granularity.
- Reviews should separate concepts, methods, formula families, and pitfalls.

## Quality expectations

- Keep each problem traceable by number.
- Do not collapse multiple exercises into one undifferentiated block.
- Mark borrowed answers clearly.
- When a proof or derivation is incomplete, label it for review instead of pretending completeness.

## Tags and links

- Tags: `course/calculus-ii`, `homework`, `review`, `analysis`
- Link section homework back to the course home and dashboard.
- Prefer explicit section names in titles when the source provides them.
