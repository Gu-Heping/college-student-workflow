# 考试资料入口参考模板：让读者找到下一页

供 AI 写或优化 README 时参考，不是另一个必须新增的备考指南。入口只负责事实、覆盖范围和导航；教学主体在题型页内。下方是写法示例，课程、材料和链接必须换成实际存在的内容，不能当作一份真实考试的资料。

## 入口页的成品版式

### 考什么，以什么为准

先用几句话说明已知考试范围、形式与最新来源。老师说“以例题和布置习题为主”，就保留“为主”，不要改写成“只会考这些题”。

没有可靠频率、分值或细则时不摆空栏，不推算分数。历史卷上印出的分值可以跟着具体题保留，不外推为本次考试的分值。

### 从哪开始

| 当前需要 | 去哪里，做什么 |
| --- | --- |
| 完全没学过 | 打开按依赖排列的第一份题型页，先读概念与第一道完整例题 |
| 知道知识点但不会选方法 | 打开对应页的方法说明，对照题目要求和已知条件找切入点 |
| 某一步推不下去或不知道怎样表达 | 到该页的具体解题过程和概念说明，而不是只找另一张速记表 |
| 想判断是否掌握 | 做该页没有讲过的独立真题，再看后面的答案与解析 |
| 已经会做，只想回顾 | 跳到各页速查和易错点 |

正式入口应把“第一份题型页”“对应页”换成准确的可点击目标，不留这些泛称。按知识依赖导航，不因为某一章历史题多，就让零基础读者跳过必需的概念。

这张表不是日程表。除非用户要求并提供约束，不写“每天 90 分钟”“三天学完”或无依据的考试收益。

### 范围如何落到题型页

| 来源条目 | 题型页 | 在哪里讲清楚 | 当前状态 |
| --- | --- | --- | --- |
| 老师清单里的一个知识点 | 实际页面链接 | 概念、适用条件、对应解法 | 已讲清 / 只提及 / 待补 |
| 一道历史题 | 实际例题或自测位置 | 题面和完整解答，而非只列题号 | 已融入 / 待补 |
| 习题课新增的方法或更正 | 受影响的原页面 | 改了哪个概念、方法分支及解答 | 已整合 / 有冲突 |

只列对读者有用的条目，不为追求表格数量重复完整证据库。“已讲清”需要 AI 读正文判断；标题命中或链接有效只能说明已经定位。

### 资料放在哪里

- **题型解析**是主要阅读位置：必要概念、解题方法、例题、自测与答案都在页内。
- **试卷精析**用于按卷核对题目，存在时给出入口；不要再复制一套不一致的题解。
- **分析与来源**供需要核对范围和出处时查阅，不要求学生先读机器状态、JSON 或 sidecar 行号。
- 单独的公式卡、模板卡、术语表只在实际常用或用户要求时保留。少文件不是目标；少来回寻找、少重复维护才是目标。

### 确有影响的局限

只说明会影响当前使用的缺口及处理方式。例如某一题的图看不清，就标出哪题、哪些条件尚不确定；不要把整页写成反复提醒用户“未经人工核验”的审计报告。AI 核对过什么、委派给谁、哪些检查通过，放进本轮 reader audit。

## 调整方式

用户不满意入口时，先看是找不到教学页、信息过多、范围不准，还是阅读顺序跳跃，再改对应内容。不要把“精简”自动理解为删成一个文件，也不要用另一份说明书解释原说明书。没有独立用途的栏目就不生成。
