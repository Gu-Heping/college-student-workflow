# 题型讲义写作参考：从理解到独立作答

供 AI 写作和审稿时参考，不是脚本填空骨架，也不是每页必须复制的目录。先读取本课程材料、真实题目、答案和用户当前反馈，再亲自编辑。已有页面保留有效结构，只改需要改的部分。

本参考不预设学科。计算、证明、论述、案例分析、图表解读、实验设计等任务，应按实际考查方式选择讲法；不能把所有题目都写成“记公式 → 代数值 → 验算”。下文描述成品应达到的效果，不提供可冒充真实课程内容的演示题。

## 首屏：知道本页学什么、从哪开始

开头说明本页解决哪类实际作答困难，以及读完能独立完成什么。不要只列知识点名称。

- 没学过：指向本页必要概念和第一道完整例题。
- 已理解但不会用：指向方法选择与适用条件。
- 考前回顾：指向已讲清内容的速查段。

只有来源支持时才写频率、分值或考试要求；没有依据就不设空栏。阅读路径不是学习日程，不自动编排耗时和提分收益。

## 知识讲解：把术语变成能执行的理解

在第一次使用概念时，讲清它指什么、为何需要、如何判断或使用。术语表只供查阅，不能代替解释；来源链接也不能代替正文。

针对实际材料，选择必要的讲解方式：

| 学生卡在哪里 | 正文应补什么 |
| --- | --- |
| 认识名称，却不知道在说什么 | 用明确的对象、关系或情境解释含义，区分容易混淆的概念 |
| 记得结论，却不知道何时能用 | 说明成立条件、判断信号和不适用情形 |
| 能看懂答案，却不知道怎么起步 | 从题目中的具体条件走到第一个可执行动作，解释选择理由 |
| 能跟一遍，却不会另一种问法 | 对比条件变化如何改变方法、论证或答案组织 |
| 某一步突然跳过去 | 补出依赖的知识与中间推理，不用“显然”或“按模板”跳过困难 |

是否需要公式推导、图示、概念对比、论证链或操作演示，由内容决定。必要时可用短小的教学演示帮助理解，但须明确它不是往年卷例题或自测，不能取代真实题目。

课本、讲义等依据必须实际读取。正文把知识讲清，准确出处放在合适位置或来源附录；不要让读者靠机器引用、sidecar 行号或宽泛书名自行补齐讲解。

## 方法选择：不是万能步骤清单

说明题目出现哪些条件时采用什么方法，为什么适用，怎样开始，遇到不同条件怎样调整。分支只来自真实题目与课程知识，不为凑数量制造“方法卡”。

方法的表达应适合任务：有的需要推导与计算，有的需要选择证据、组织论点、解释材料或设计验证。不要强迫所有方法都有数值、公式或同一种答案结构。

速查只压缩已经讲过的内容。第一次学习所需的理由不能全藏进另一张卡，口诀也不能与正文条件冲突。

### 把方法写到学生能迁移

每种核心方法要讲到学生能独立执行，而不是只认识名称：

- **识别与边界**：哪些条件支持使用它，哪些相似情形不能用；若有多种方法，比较选择依据，而非只列名单。
- **起步与过程**：从题面提取什么、先作哪个判断或动作、后续如何推进；解释关键转折为什么成立，补出学生尚不会的操作。
- **结果与核对**：怎样回应全部设问，怎样检查遗漏、论证缺口或结果矛盾。
- **变式与迁移**：说明条件、设问或材料变化后，哪些步骤保留、哪些必须调整。例题之间要有具体对比，不用一句“同理可得”代替迁移讲解。

方法讲完后，AI 必须拿本题型实际收录的每道题尝试走一遍：能否仅凭本页已经讲清的知识和方法完成？如果遇到新的关键步骤，补方法、补前置知识或调整题型边界，不把不会解的题硬贴到现有方法名下。

“覆盖所有题目”指已读取、纳入当前范围的题池，不是对未知考试的保证。遗漏题、证据不全题和暂未覆盖的方法明确列出，不能用覆盖率或表格标签掩盖。

## 例题：让学生跟着真正做完

从实际读取的往年卷选择能教会核心方法和常见变式的题目。每道例题至少把以下问题讲明白，但不必逐项变成小标题：

1. **完整题面与来源**：条件、材料、图示和全部设问足够作答；不能只放题号或答案摘要。
2. **读题与选法**：指出本题哪个具体条件决定切入方式，不写“根据关键词选择合适方法”。
3. **解题过程与理由**：处理各个设问，保留关键中间推理，解释困难的转折；不能用通用解析替换本题的实际过程。
4. **明确答案**：回应题目要求。需要论证就给出论证，需要比较就交代比较依据，不能把过程机械压成一个结论。
5. **核对与迁移**：用适合本题的方式核对答案，并说明另一道题中哪些条件变化会影响做法。检查理由写成有用讲解，不堆“自检通过”标签。

同一题的另一种解法可放在本例后比较，但不因此变成一道新的独立自测。用户明确纳入教材题、老师习题时，保留真实来源身份，不改标为往年卷。

## 自测：独立检验方法，而不是重复例题

选题前给例题与自测分别留出题池。两组都要考虑核心方法和主要变式的覆盖，不能把所有可用题耗在例题里。

例题组负责把方法教会，自测组独立检验同样的核心方法和主要变式。AI 要逐项核对两组的覆盖；一题可训练多个方法，但应在实际解析中用到，不能靠附加标签凑齐。若某方法只有一道可用真题，说明无法同时满足教学和独立自测的缺口，不复制同题或偷偷补编题。

自测题完整写出题面、来源和训练目标；提示只在必要时提供，避免直接泄露答案。答案区独立放后，给出具体结论、关键过程及核对依据，让学生知道错在理解、选法还是执行。

例题与自测默认全部来自往年卷，且不能重复同一道题；换解法、改标题或遮住例题答案不算新题。真题不足时减少数量并说明缺口，不用自编题冒充。若用户明确改变选题来源要求，按其要求调整并准确标注。

## 可读性与审稿

- 按实际学习依赖安排内容，短段、表格、步骤、图示按需要使用；不用固定栏目数量代替讲解。
- 易错提醒要指出具体错误与修正动作，不写泛泛的“仔细审题”。
- 新材料影响了原有概念或方法时，修改对应讲解与例题，不只追加链接。
- 主 agent 读回磁盘上的成品，按学生首次学习与独立作答的过程走一遍。Subagent 可以写草稿，但不能替代主 agent 的审稿责任。
- 用户调整结构、深度或表达时，修改实际正文，并将适用偏好落实到本课程；不要把局部偏好升级成所有学科的硬规则。
- 机械检查只守格式、来源与去重等底线；不能证明讲解易懂、推理正确或学生已学会。
